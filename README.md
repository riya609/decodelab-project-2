## 🚀 Features

- 📄 Create, Read & Delete Notes
- ⚡ RESTful API Endpoints
- ✅ Server-side Validation
- 📦 JSON Responses
- 🌐 CORS Enabled
- 💾 In-Memory Data Storage

## ▶️ Getting Started

Install dependencies:

```bash
npm install
```

Run the server:

```bash
node server.js
```

Open your browser:

```
http://localhost:3000
```

---

## 📡 API Endpoints

- `GET /api/status`
- `GET /api/notes`
- `GET /api/notes/:id`
- `POST /api/notes`
- `DELETE /api/notes/:id`
