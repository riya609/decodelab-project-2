A RESTful API,
built from scratch.

GET, POST, and DELETE endpoints — with data validation, proper HTTP status codes, and JSON responses. No database, no framework — just Node.js + Express.

GET /api/notes POST /api/notes GET /api/notes/:id DELETE /api/notes/:id GET /api/status

POST Create a Note

Sends a POST request to /api/notes. Fields are validated server-side.

GET Fetch Notes

Sends a GET request to /api/notes. Filter by subject optionally.

DELETE Delete a Note

Sends a DELETE request to /api/notes/:id. Returns 404 if not found.

GET Live Notes List

Click "Refresh" to load all notes.

Reference

HTTP Status Codes used in this API

200 OK GET / DELETE success
201 Created POST — new note added
400 Bad Request Validation failed
404 Not Found Note ID doesn't exist
500 Server Error Unexpected crash
